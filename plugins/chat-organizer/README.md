# Chat Organizer

In a Codex desktop chat, select **Chat Organizer** from the plugin picker and try “Find my projectless Codex chats and suggest where they belong.” The plugin uses your desktop's native sidebar actions and your existing projects. A general cleanup starts with a preview.

To act on a suggestion, ask for the specific move, pin, rename or archive operation. A project controls chat membership. A custom sidebar section groups related chats or projects for navigation. Recents can also show a chat filed in a project.

This package includes one skill, `organize-sidebar`. It requires Codex desktop with the built-in chat and sidebar tools. Older clients may expose fewer actions.
